Why the “One Shot Trello” is the wrong game

Trello link lists pair the board trello.com/b/Mnpfw4C5 with Roblox place 11481193418 and the Discord discord.gg/y6SCcscGx9. We checked both:

Item on link sitesWhat it really is
Place 11481193418One Shot Remastered by Tempest Media, a One Punch Man training game (pushups, squats, situps)
discord.gg/y6SCcscGx9The Tempest Media Discord server
Tier lists with Katana, Greatsword, “skills”Melee/skill lists that do not match One Shot's one-bullet guns

So that Trello will not help with One Shot's codes, guns, events or Ranked mode.
