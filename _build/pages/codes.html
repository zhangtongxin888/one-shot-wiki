How to redeem codes in One Shot

01

Join Shooter Game Group

Join the creator's Roblox community, Shooter Game Group ↗. Code trackers agree the code box will not pay out without it.

02

Open the Store

Launch One Shot and press the STORE button at the bottom of the screen.

03

Scroll to “Enter Code...”

Scroll to the bottom of the Store menu and type or paste a code into the “Enter Code...” box.

04

Press REDEEM

Press REDEEM. The crate is added to your inventory and can be opened from the Store.

CODE NOT WORKING?

1) Check you joined Shooter Game Group with the same account. 2) Retype it in capitals with no spaces. 3) Rejoin a new server, as older servers can run an older version. 4) If it still fails, the code has probably been switched off; FREE12 is the most likely to fail.

What the crates give you

Codes give three crate types: Crate, Premium Crate and Release Crate. Crates open into weapon skins; the official listing describes “rare & limited weapon skins”. Code guides describe the skins as cosmetic, and the game sells no game passes, so codes help you collect skins rather than buy power. Drop odds are not published. Crate and progression guide →

One Shot codes FAQ

Are there new One Shot codes for the Autumn Event?

The Autumn Event ended Oct 16, 2026, but its code FREE28 (1 Autumn Crate) is still listed as active by Roblox Den and Roburo.jp on Oct 23. No newer code has been listed since.

Why does One Shot say my code is invalid?

Most often you have not joined Shooter Game Group, or the code was typed in lowercase. FREE12 is disputed and may be expired.

Where do new One Shot codes come out?

Code guides point to the “[FPS] One Shot” community Discord (discord.gg/czh7DKTSu7). The Roblox page itself does not list codes.

Is the One Shot Trello a code source?

No. The Trello most link sites share belongs to One Shot Remastered, a different game. See our One Shot Trello & Discord check.

Stay safe

Never enter a Roblox password into a third-party code page, and never install software that promises free items. Codes are only redeemed inside the game.
